# 🆘 Support

## Where to ask

- **Bug:** Open a [bug report](https://github.com/Brajesh31/Contact-Searching-Application/issues/new?template=bug_report.yml).
- **Feature proposal:** Open a [feature request](https://github.com/Brajesh31/Contact-Searching-Application/issues/new?template=feature_request.yml).
- **Documentation:** Open an issue using the documentation template.
- **Security issue:** Follow [SECURITY.md](SECURITY.md), not a public issue.

## Before opening an issue

Include the operating system, compiler and version, exact command used, expected behavior, actual behavior, and reproducible steps. Replace names, phone numbers, and emails with synthetic values.

## Common setup checks

- Ensure the compiler supports GNU C++17.
- Compile from the repository root.
- Run the executable from the repository root so `contacts.txt` can be found.
- Confirm the working directory is writable because the application rewrites `contacts.txt` after menu operations.
- Keep a backup of your local contact file before experimenting.

There is no published response-time or service-level guarantee.
