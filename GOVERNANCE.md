# 🏛️ Project Governance

## Ownership

This is an individually maintained repository. Brajesh Kumar is the repository owner and maintainer.

## Decision process

The maintainer reviews proposed scope, prioritization, security reports, and changes. Significant technical changes should be discussed through an issue before implementation.

## Contribution review

Pull requests should be focused, explain their evidence, and include relevant validation. Documentation must describe implemented behavior accurately and distinguish proposals from current functionality.

## Scope protection

Application source code, application behavior, data files, dependencies, and build/editor configuration remain protected unless the maintainer explicitly authorizes a separate application-change task.

## Changes to this policy

Policy updates are reviewed by the repository maintainer and recorded in repository history.
