# 🔒 Encryption

The current application stores contacts.txt and generated VCF files as plaintext. It does not encrypt data at rest, encrypt exports, or communicate over a network.

Protect local data through operating-system account permissions and encrypted storage supplied by the host environment. These are host-level controls, not features implemented by the program.

No cryptographic algorithm, key management, encrypted format, or encryption compliance claim applies to the current source.
