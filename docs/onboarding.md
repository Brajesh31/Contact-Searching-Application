# 👋 Contributor Onboarding

1. Read README.md and docs/README.md.
2. Review CODE_OF_CONDUCT.md, CONTRIBUTING.md, and SECURITY.md.
3. Understand that the application is a single-file C++ CLI.
4. Review docs/architecture.md and docs/data-format.md.
5. Build with GNU++17.
6. Run tests/test_cli_smoke.py with disposable data.
7. Use synthetic contact values only.
8. Submit focused documentation, test, or repository improvements with evidence.

Application source changes are outside the current repository-enhancement scope unless separately authorized.
