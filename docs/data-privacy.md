# 🔐 Data Privacy

## Data categories

- Contact name.
- Telephone number.
- Email address.

## Processing

Values are read from terminal input or contacts.txt, stored in process memory, written back to contacts.txt, and optionally exported to a vCard file.

## Privacy risks

All files are plaintext. The application has no authentication, authorization, encryption, consent workflow, retention scheduler, or secure erasure.

The project documentation is not legal advice or a regulatory compliance statement.
