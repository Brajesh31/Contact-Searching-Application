# 🔁 Change Management

For repository-support changes:
1. Inspect the current tree and branch.
2. Identify the applicable checklist requirements.
3. Keep source/data/configuration protection explicit.
4. Create a focused commit.
5. Run the relevant workflows.
6. Verify the final tree and preserved file hashes.
7. Report additions, modifications, omissions, and evidence.

Any proposed application behavior change should be raised separately and reviewed before implementation.
