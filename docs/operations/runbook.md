# 📝 Local Operation Runbook

## Start

1. Confirm the executable was built for the current platform.
2. Verify contacts.txt is present in the current working directory.
3. Confirm you have a private backup of data you intend to preserve.
4. Launch the executable.

## During use

- Select menu options and provide expected input.
- Use synthetic records in demonstrations.
- Remember that non-exit menu iterations rewrite contacts.txt.

## Stop

Select menu option 8. Confirm the application exits. Review the data file if the session changed records.

## Escalation

For build or runtime problems, follow SUPPORT.md. For suspected exposure of personal data or a security issue, follow SECURITY.md.
