# 🪦 Deprecation Policy

There are no published releases or stable public API, so no formal deprecation timeline is active.

For any future user-visible menu or file-format change:
1. Record the reason and affected behavior.
2. Document migration or backup requirements.
3. Announce the change in release notes.
4. Preserve backward compatibility where practical.
5. Remove obsolete behavior only after an explicit decision and appropriate tests.
