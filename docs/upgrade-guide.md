# ⬆️ Upgrade Guide

The repository has no formal tagged release series. To update a local source checkout, obtain the new commit and rebuild the executable with GNU++17.

Before upgrading a working data set:
1. Back up contacts.txt.
2. Review the changelog and known issues.
3. Compile the new source.
4. Test it in a separate directory with synthetic records.
5. Restore or copy private contact data only after validation.

No data migration is performed automatically.
