# 🔏 Privacy Overview

The application handles contact names, phone numbers, and email addresses. It stores them in a local plaintext file and can create plaintext vCard exports.

The program does not implement user accounts, consent capture, encryption, data-retention automation, privacy notices, remote processing, analytics, or third-party data sharing.

Users should keep real address books out of the public repository and use synthetic data for all examples, tests, and demonstrations.
