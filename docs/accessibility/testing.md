# ♿ Accessibility Testing Notes

No formal accessibility test report was found in the initial repository. The application is terminal-based, so manual testing should record:

- Terminal emulator and version.
- Operating system and display scaling.
- Screen reader and version, if used.
- Keyboard-only operation.
- Readability at narrow terminal widths.
- Whether prompts and errors are understandable without color.
- Any focus, output ordering, or announcement issues.

Use the [review checklist](review-checklist.md). This is not a WCAG conformance statement.
