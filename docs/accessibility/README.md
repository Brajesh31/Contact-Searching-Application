# ♿ Accessibility

This is a terminal application, not a graphical web interface. Accessibility evaluation therefore focuses on text clarity, keyboard-driven interaction, terminal compatibility, and avoiding color-only communication.

## Current interface observations

- Menu choices are numeric.
- Prompts and result messages are text.
- No mouse interaction or graphical widgets are implemented.
- No formal screen-reader, terminal emulator, or WCAG audit has been conducted.

## Review guidance

See [accessibility review checklist](review-checklist.md). Do not claim conformance without a completed audit and evidence.
