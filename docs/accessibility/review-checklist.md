# ♿ Terminal Accessibility Review Checklist

Use this checklist during a manual review. Items are not marked complete because no full accessibility audit has been recorded.

- [ ] Menu options are understandable without relying on color.
- [ ] Prompts identify the field being requested.
- [ ] Error messages identify the invalid or missing input.
- [ ] Output remains readable at common terminal widths.
- [ ] Keyboard-only operation is possible through standard input.
- [ ] Output does not depend on ANSI color for meaning.
- [ ] Screen-reader output is understandable in the tested terminal.
- [ ] Long contact lists can be reviewed without ambiguous formatting.
- [ ] Tested terminal and screen-reader versions are recorded.
- [ ] Findings and reproduction evidence are documented.

This checklist is a review aid, not a WCAG certification.
