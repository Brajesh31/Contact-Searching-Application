# 🖥️ Local Environment Setup

| Tool | Need | Purpose |
|---|---|---|
| Git | Optional for source checkout | Version control |
| GCC-compatible compiler | Required | Build GNU++17 source |
| Terminal | Required | Interactive input/output |
| Python 3 | Required for repository tests | Documentation and CLI test scripts |
| GitHub Actions | CI environment | Build, smoke test, documentation validation, CodeQL |

No Node.js runtime, npm, Python package set, SQL server, Docker engine, or cloud account is needed by the application.
