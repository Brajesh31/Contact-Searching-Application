# 🔐 Security and Privacy

## Data sensitivity

A contact record includes a person's name, telephone number, and email address. Treat the data as personal information even when the project itself is a small local CLI.

## Safe repository use

- Keep real address books outside version control.
- Do not attach real `.vcf` exports to issues or pull requests.
- Use synthetic values in screenshots, test cases, and examples.
- Inspect `git diff --cached` before committing.
- Avoid copying live contact data into terminal logs or CI output.

## Application observations

The source reads a relative local file and accepts terminal input. It performs limited validation and writes the full contact list back to the data file. The repository has not been independently security-audited.
