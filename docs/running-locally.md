# ▶️ Running Locally

From the repository directory:

~~~bash
./contact-search
~~~

On Windows PowerShell:

~~~powershell
.\contact-search.exe
~~~

The executable reads contacts.txt from the process current working directory. It writes updated contact data to that path after non-exit choices. Option 3 creates a name-derived VCF file in that same directory.

Run from a disposable copy if you do not intend to overwrite the repository's tracked contact data.
