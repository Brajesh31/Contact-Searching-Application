# 🌱 First Contribution

Good first tasks include correcting a verified documentation issue, improving the terminal smoke-test coverage, adding a source-backed diagram, or strengthening a repository validator.

## Before opening a pull request

- Reproduce the behavior with synthetic data.
- Keep main.cpp and tracked contact files unchanged unless the task explicitly authorizes otherwise.
- Run documentation validators and the CLI smoke test.
- Confirm no private contact information or credentials are included.
- Explain the exact verification performed and what remains untested.
