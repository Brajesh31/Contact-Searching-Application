# 🔄 Product Lifecycle

This is a small source repository without a formal release train or service lifecycle. The practical lifecycle for the current project is:

1. **Source maintenance:** preserve the existing C++ behavior unless a separately approved code change is made.
2. **Repository improvement:** update docs, diagrams, templates, and quality automation with verified facts.
3. **Build verification:** compile using GNU++17.
4. **Behavior verification:** run the disposable-data CLI smoke test and additional manual cases.
5. **Review:** inspect source changes, privacy risks, and evidence.
6. **Release planning:** define version numbers and release notes before publishing formal releases.

There is no deployed service, production tenant, subscription lifecycle, or automated deprecation process.
