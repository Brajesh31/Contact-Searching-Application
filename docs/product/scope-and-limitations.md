# 📏 Product Scope and Limitations

## In scope today

- Local terminal interaction.
- Contact record with name, phone number, and email.
- Add, exact search, partial-name search, update, delete, list, and export.
- Local text-file persistence.

## Outside current scope

- Browser/mobile app.
- Multi-user or synchronized address book.
- User authentication and authorization.
- Network API or database server.
- Cloud backup, encryption, and account recovery.
- Advanced fuzzy matching or ranking.
- Automated data import pipeline.

See [known limitations](../known-limitations.md) for source-level details.
