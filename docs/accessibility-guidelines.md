# ♿ Terminal Accessibility Guidelines

For future authorized interface changes:

- Keep menu options numeric and clearly labeled.
- Do not rely on color, animation, or symbols alone to communicate state.
- Make prompts identify the exact field expected.
- Keep error messages specific and actionable.
- Avoid unnecessary console clearing or cursor-position tricks.
- Test keyboard-only use.
- Check output in narrow terminal windows.
- Verify that screen readers announce prompts and result text in a comprehensible order.
- Record terminal, OS, and assistive-technology versions when reporting findings.

These are recommendations. No conformance audit has been performed.
