# 🐙 GitHub Actions Workflows

## Active workflows

- docs-validation.yml: validates Markdown local links, SVG XML/accessibility elements, Mermaid source structure, MIT markers, and protected file hashes.
- cpp-build.yml: compiles main.cpp with GNU++17 and runs the CLI smoke test.
- codeql.yml: initializes CodeQL for C++, compiles the translation unit for tracing, and uploads analysis.

## Other configuration

- dependabot.yml: monthly updates for GitHub Actions only.
- Issue forms: bug, feature, documentation, accessibility, performance, and question.
- Pull request template: summary, scope, tests, privacy, and evidence.

Repository Discussions are disabled, so discussion category templates are not added. Release/stale automation is not enabled because no release cadence or issue-management policy has been established.
