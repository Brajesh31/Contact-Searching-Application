# 📊 Test Coverage

No line or branch coverage tool is configured. The current automated smoke test verifies a small set of application journeys, but it does not measure source-code coverage.

| Area | Coverage state |
|---|---|
| Startup load | Smoke-tested |
| Add | Happy path smoke-tested |
| Exact search | Name-match smoke-tested |
| Partial search | Substring smoke-tested |
| Persistence | Temporary-file rewrite smoke-tested |
| VCF export | Happy path smoke-tested |
| Delete and modify | Manual plan only |
| Invalid and malformed inputs | Manual plan only |
| File failures | Not automated |
| Performance and resource limits | Not measured |

Do not report a coverage percentage without a coverage instrument and reproducible report.
