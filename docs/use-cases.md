# 🧑‍💻 Use Cases

The detailed use-case records are maintained in [product/use-cases.md](product/use-cases.md). The following table maps each user goal to the real menu flow.

| ID | Goal | Entry point | Result |
|---|---|---|---|
| UC-01 | Start | Launch executable | Existing file rows are loaded, then menu is shown |
| UC-02 | Add | 1 | Insert after basic checks |
| UC-03 | Delete | 2 | Remove the first matching phone |
| UC-04 | Export | 3 | Attempt a name-derived vCard file |
| UC-05 | List | 4 | Print contacts sorted by name |
| UC-06 | Exact lookup | 5 | Print exact name or phone matches |
| UC-07 | Partial lookup | 6 | Print consecutive case-insensitive name matches |
| UC-08 | Modify | 7 | Prompt for replacement values |
| UC-09 | Exit | 8 | Terminate with exit code 0 |
