# 👥 Ownership Matrix

| Asset | Accountable role | Review requirement |
|---|---|---|
| main.cpp | Repository maintainer | Application change requires explicit scope authorization |
| contacts.txt and VCF files | Data owner / repository maintainer | Privacy review before publication |
| README and docs | Repository maintainer | Source accuracy and link check |
| GitHub Actions | Repository maintainer | Workflow permissions and runtime review |
| Tests and scripts | Repository maintainer | Test isolation and preservation checks |
| LICENSE and governance | Repository maintainer | Ownership and legal-text review |

CODEOWNERS assigns repository-wide ownership to the configured maintainer account. This matrix does not imply additional personnel.
