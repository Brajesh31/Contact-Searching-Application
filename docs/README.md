## 🔎 Scope notes

This is a single-process CLI project. Browser routing, frontend component libraries, backend APIs, database schema, authentication, webhooks, cloud hosting, server monitoring, payments, and AI/ML subsystems are not present in the inspected code. Their absence is recorded rather than filled with imaginary documentation.
