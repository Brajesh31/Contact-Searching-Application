# 🗄️ Data Governance

The application has no role-based data ownership or centralized data governance system.

The local operator is responsible for:
- Choosing which contact data is stored.
- Keeping the data file private.
- Maintaining backups.
- Deleting records and backups when appropriate.
- Reviewing VCF exports before sharing.
- Keeping real contact information out of public commits and issue reports.

The repository maintainer is responsible for reviewing public examples and repository changes, not for data stored on users' local machines.
