# 🛡️ Security Best Practices

## For users

- Use synthetic records in demonstrations.
- Run experiments in a private disposable checkout.
- Back up contacts.txt before a session.
- Keep real address books and backups outside version control.
- Verify VCF export files before sharing.
- Restrict file permissions through the operating system.

## For contributors

- Review staged changes before pushing.
- Do not attach contact exports to public issues.
- Use private vulnerability reporting for security findings.
- Keep GitHub Actions permissions read-only unless a workflow requires more.
- Review third-party Actions updates and pinning policy.
- Do not claim an audit passed based only on the presence of CodeQL configuration.
