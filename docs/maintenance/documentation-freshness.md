# 🕒 Documentation Freshness

Review documentation whenever the C++ source, menu, contact data format, compiler settings, or export behavior changes.

Suggested review triggers:

- A new or changed menu option.
- A change to Contact fields or persistence.
- Changes to hash-table insertion or rehashing.
- Changes to input validation.
- Changes to the VCF export format.
- Changes to compiler/toolchain assumptions.
- A new release or dependency.

Do not use artificial hourly timestamp updates. Record review dates only when a real review occurs.
