# ♿ Accessibility Overview

The project is a terminal interface, not a graphical website. The accessibility scope is therefore keyboard operation, readable text prompts, meaningful errors, terminal compatibility, and screen-reader interaction.

No formal WCAG 2.2 AA assessment is claimed. WCAG may inform general thinking, but the current repository does not implement a web UI.

See the [review checklist](accessibility/review-checklist.md), [keyboard navigation notes](keyboard-navigation.md), and [testing notes](accessibility-testing.md).
