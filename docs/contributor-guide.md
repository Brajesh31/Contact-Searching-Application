# 🤝 Contributor Guide

Read CONTRIBUTING.md and the [first contribution guide](first-contribution.md). Contributions should be focused, evidence-backed, and privacy-safe.

Preferred repository-level contributions include:
- Accurate documentation.
- Editable diagrams.
- Validation scripts.
- Synthetic-data tests.
- GitHub forms and workflows.

Application code, IDE/compiler configuration, and tracked contact data are preserved under the current repository-enhancement task scope.
