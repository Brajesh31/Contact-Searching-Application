# 🌱 Code of Conduct

## Our standard

We aim to maintain a respectful, constructive, and inclusive project space.

Examples of expected behavior:

- Be considerate and professional.
- Discuss technical ideas, not personal attributes.
- Give actionable feedback and accept corrections.
- Respect privacy and never publish another person's contact details.
- Help keep discussions focused and welcoming.

Unacceptable behavior includes harassment, insults, threats, discriminatory language, doxxing, sharing private contact information, and deliberately disruptive conduct.

## Scope

This policy applies to repository issues, pull requests, discussions, code reviews, and project-related communication.

## Reporting

Report conduct concerns privately to the repository maintainer through the contact method available on the maintainer's GitHub profile. Do not include sensitive personal information in public issues.

## Enforcement

The maintainer may edit or remove inappropriate content, close discussions, restrict participation, or block accounts depending on severity. Reports will be reviewed with discretion.

This project is maintained by an individual; no formal enforcement committee is currently established.
